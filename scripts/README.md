The scripts to train the segmentation model are three:
1. data: uploads the data, which should be stored in a folder (I named it "tusimple_multiclass", modify to whatever you used locally)
   and include train/valid/test partition
2. multi_classes: contains all the functins built for training
3. run_code: actually runs the training (uploads the data, defines hyperparameter, trains the model, prints and save outputs)
